# taktboard

A construction schedule timeline board with delay propagation: trades, day-granular
tasks, finish-to-start dependencies, and a visible downstream ripple when a task slips.
Standalone portfolio project — the engineering process is part of the deliverable.

## Quick start

```sh
git clone https://github.com/husnukirci/taktboard.git
cd taktboard
npm ci
npm run dev
```
